# Loan Approval Prediction using Logistic Regression

This project predicts whether a loan will be **approved or rejected**
based on applicant information using **Logistic Regression**.

---

## 📊 Dataset
The dataset includes the following features:
- Applicant income
- Loan amount
- Education
- Employment experience
- Loan intent
- Home ownership
- Loan status (target variable)

---

## ⚙️ Steps Performed
1. Data cleaning
2. Exploratory Data Analysis (EDA)
3. Feature encoding using one-hot encoding
4. Train-test split
5. Model training
6. Model evaluation

---

## 🧠 Model Used
- Logistic Regression

---

## 📈 Results
- Accuracy: ~89%
- Precision: ~77%
- Recall and F1-score evaluated
- Confusion matrix used for performance analysis
